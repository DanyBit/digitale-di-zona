# Digitale di Zona 📍

**Supporto digitale per attività locali a Cantù e dintorni.**

Digitale di Zona nasce con un obiettivo semplice: aiutare negozi, professionisti e piccole attività a gestire meglio la propria presenza digitale, senza complicazioni e senza linguaggio tecnico inutile.

## Cosa faccio

- 🌐 Siti web
- 📍 Google Business
- ⭐ Recensioni
- 📱 QR Code e NFC
- 🛠 Supporto digitale
- 🤝 Assistenza anche di persona

L'obiettivo non è semplicemente vendere un sito o un servizio, ma diventare un punto di riferimento locale per tutte quelle esigenze digitali che spesso vengono rimandate o lasciate senza un referente.

> **Non devi sapere come funziona. Devi solo sapere chi chiamare.**

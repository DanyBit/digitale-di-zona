# Digitale di Zona — GitHub Pages

Landing page statica pronta per GitHub Pages.

## Pubblicazione rapida
1. Crea un repository GitHub (es. `digitale-di-zona`).
2. Carica `index.html`, `styles.css` e la cartella `assets` nella root del repository.
3. Vai in **Settings → Pages**.
4. In **Build and deployment**, scegli **Deploy from a branch**.
5. Branch: `main`, cartella: `/ (root)`.
6. Salva e attendi la pubblicazione.

## Da personalizzare appena vuoi
- Le CTA puntano per ora a Instagram: https://www.instagram.com/digitaledizona.cantu/
- Quando hai WhatsApp Business, sostituisci i link CTA con il tuo link `wa.me`.
- Se compri un dominio, collegalo da Settings → Pages → Custom domain.
